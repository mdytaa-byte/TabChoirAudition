Rhythm Notation Fundamentals

1. Note Values

Music measures duration using note values.

Whole Note
4 beats
Half Note
2 beats
Quarter Note
1 beat
Eighth Note
½ beat
Sixteenth Note
¼ beat

2. Rests

Rests represent silence.

Rest Value
Whole Rest 4 beats
Half Rest 2 beats
Quarter Rest 1 beat
Eighth Rest ½ beat

3. Dots

A dot adds half the value of the original note.

  • Quarter = 1 beat
  • Dotted Quarter = 1.5 beats
  • Half = 2 beats
  • Dotted Half = 3 beats

4. Ties

A tie combines note values.

Quarter + Quarter tied = 2 beats

Half + Quarter tied = 3 beats

5. Beams

Beams connect groups of eighth and sixteenth notes.
